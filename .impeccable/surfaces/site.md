# Website

Mode: Persuade. Target: `site/src/pages/index.astro`.

## Job and audience

Terminal-first macOS developers arriving from GitHub or search. They need to
understand in seconds that lofi-hiphopper fills silence, yields to calls and
other audio, and offers six visualizers. Primary action: install. Secondary:
download the release or inspect the repository.

## Outcome and proof

Show the working terminal, real TUI screenshots, the install command, the
config sample, and the FAQ. No invented metrics, testimonials, or capabilities.
The visitor should leave knowing what it does and how to run it.

## Scope and boundaries

The Astro landing page only. Product facts, copy claims, links, screenshots,
SEO metadata, the terminal demo, and accessibility behavior stay intact. The
TUI itself is untouched. No fake typing animation, hacker cosplay, nested card
grids, hidden mobile actions, or horizontal page scroll.

## Direction contract

THESIS: The landing page is one open terminal session, not a marketing page
that contains a terminal. It refuses the narrow centered column and the
six-card feature grid.

OWN-WORLD: Near-black field, flat hairline panes, mono command lines, a
persistent session rail, one live terminal with the only deep shadow and violet
glow, and ultraviolet/hot-pink/peach concentrated in signal and action.

STORY: The visitor sees a working silence-aware radio, understands that it
yields to real audio, and runs one install command. Proof is the live terminal,
real screenshots, and the actual config output.

FIRST VIEWPORT: Full-bleed workspace. A thin top bar carries the brand, section
commands, version, and a compact install action. A narrow left session rail
lists behavior, preview, install, and FAQ with a live status readout. The main
pane opens with a command banner and the headline, a right-side install action
panel, then a full-width live terminal with radio, signal, and spectrum.

FORM: The Open Session: one terminal workspace with a session rail and a
continuous command stream. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance
